## dsh-pdl-center v1.0.0

首个公开版本：PDL 井数据整理加载中台 —— DeepSeek Harness 插件。

在 PDL 引擎（`pdl`）之上提供批次工作台与六步向导，把原始井资料整理成 GeoEast 可直接导入的加载包。

### 新增

- 批次工作台：工程 / 资料包 / 批次 / 运行 / 交付 / 参考库 / 规则模板的本地持久化索引
- 六步向导：计划预览 → 执行 → 结果核对 → 交付确认，对应 `pdl-scan → pdl-merge → pdl-export`
- 运行记录：每次运行冻结配置快照与产物摘要，产物变化后旧交付确认自动失效
- 会话右侧面板：当前阶段、待处理问题、最近产物
- Host API `POST /pdl-center/api/<method>` 与薄 Python 适配层
- 中英文界面元数据与原创 SVG 图标

### 安装

```sh
dsh plugin --profile <profile> add https://github.com/ItLeLeYa/dsh-pdl-center/releases/download/v1.0.0/dsh-pdl-center-1.0.0.tgz
```

或从源码安装：`dsh plugin --profile <profile> add github:ItLeLeYa/dsh-pdl-center`。

### 前提

- DeepSeek Harness（Web profile）
- Python 3.9+，且能从 `<projectRoot>/src` `import pdl`
- 工程目录需包含 `config/project.yaml`

### 已知限制

- 首版不在界面内逐行编辑业务数据；Excel 复核走「外部修改 → 重新检测 → 预检」
- 批量队列与跨批次增强比对未纳入首版
- 实机导入验收需人工在 GeoEast 侧记录，界面只显示「待导入」
